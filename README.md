# CreeperEyes Web-Installer

Browser-Installer (ESP Web Tools) für [tooluser/CreeperEyes](https://github.com/tooluser/CreeperEyes):
animierte „Uncanny Eyes“ auf zwei SSD1351-OLEDs (128×128) an einem klassischen ESP32.

**Installieren:** https://deffel6.github.io/creepereyes-webinstaller (Chrome oder Edge am Computer)

Die Firmware ist unverändert aus Commit `e757cca` gebaut, mit Arduino-ESP32 3.3, Adafruit GFX und Adafruit SSD1351.
Grundlage ist Adafruit „Uncanny Eyes“ von Phil Burgess (MIT-Lizenz) mit der Anpassung von Laurent Moll.
